# **App Name**: Boston Merrimack Wanderer

## Core Features:

- Activity Data Ingestion: Parse and display activities from the provided Google Sheet (CSV format) into an accessible list for planning.
- Interactive Day Planner: A user interface that allows users to easily select, drag-and-drop, and arrange activities into a daily schedule.
- Time-Aware Drive Time Calculation: Calculates and displays the estimated total drive time between sequentially selected activities for a given day, starting from Tewksbury, MA, taking into account real-time traffic conditions based on specified date/time of arrival and departure for each segment.
- Google Maps Route Generation: Generates a dynamic Google Maps link with multiple stops for the selected activities, optimized for an efficient route.
- Activity Suggestion Engine: An AI tool that provides recommendations for additional activities or sequence adjustments based on currently selected activities and available time slots.
- Optional Activity Designation: Allows users to mark certain activities as 'optional' which are displayed in the planner but not included in map routing or drive time calculations.

## Style Guidelines:

- A welcoming light color scheme designed to evoke the tranquility of the Merrimack Valley, perfect for friendly local exploration.
- Primary accent color: A serene and inviting blue (#4D99CC) that is both grounded and modern.
- Background color: A soft, heavily desaturated light blue (#ECF3F7) providing a clean and calm canvas for content.
- Secondary accent color: A fresh and complementary light blue-green (#63DBCF) used for highlighting interactive elements and important information, offering good contrast.
- A clean, modern sans-serif typeface, 'Inter', for all text, ensuring readability and a contemporary feel across headlines and body content.
- Utilize a consistent set of line-art or minimalist vector icons to represent different activity types (e.g., dining, nature, art, historical sites) and navigation controls.
- Employ a clear and intuitive layout, possibly with a split-screen or drag-and-drop interface, making the planning process engaging and easy to understand.
- Incorporate subtle and smooth animations for drag-and-drop actions, activity selections, and map transitions to enhance user interaction and feedback.
